Deep Learning Quick Reference Cheatsheet

=== ARCHITECTURE COMPARISON ===
VGG: very deep CNNs with 3x3 convolutions, no skip connections. Many parameters.
ResNet: residual/skip connections solve vanishing gradients. Identity shortcut: y = F(x) + x.
Inception (GoogLeNet): parallel convolutions with different kernel sizes concatenated.
DenseNet: each layer connects to all subsequent layers. Feature reuse.
MobileNet: depthwise separable convolutions for efficiency on mobile devices.
EfficientNet: scales depth/width/resolution uniformly using compound scaling.

=== KEY PROPERTIES ===
CNN: translation invariance via weight sharing. Spatial feature extraction.
RNN/LSTM: handles variable-length sequences. State carries temporal information.
Transformer: global attention. Parallelisable. Scales well with data and compute.
GAN: generator + discriminator trained adversarially. Mode collapse is a failure mode.
VAE: encodes input into latent distribution (mean + variance). KL divergence term in loss.

=== COMMON MISTAKES / TRAPS ===
Using sigmoid output with cross-entropy → use softmax instead for multi-class.
Forgetting to normalise inputs → training instability.
Too large learning rate → loss diverges (NaN).
Too small learning rate → very slow convergence.
No weight initialisation → all neurons learn same features (symmetry breaking problem).
Batch size of 1 is noisy SGD. Very large batch → sharp minima, poor generalisation.

=== PARAMETER COUNT SHORTCUTS ===
1x1 convolution: used for channel mixing, does not change spatial size.
Depthwise conv: C filters each applied to one input channel. Params = k*k*C.
Pointwise conv: 1x1 conv for channel projection. Params = C_in * C_out.

=== TRAINING TIPS ===
Warm-up: start with small lr, increase for a few epochs, then decay.
Cosine annealing: lr decays as lr = lr_min + 0.5*(lr_max - lr_min)*(1 + cos(pi*t/T)).
Gradient accumulation: simulate large batch by accumulating gradients over multiple steps.
Mixed precision (FP16/BF16): reduces memory, speeds up training on modern GPUs.
Gradient checkpointing: recompute activations during backward pass to save memory.

=== NORMALISATION COMPARISON ===
Batch Norm: normalises over (N, H, W) for each channel. Depends on batch size.
Layer Norm: normalises over (H, W, C) for each sample. Batch-size independent.
Instance Norm: normalises over (H, W) per sample per channel. Used in style transfer.
Group Norm: normalises over groups of channels. Works with small batches.

=== COMMON DL MCQ ANSWER PATTERNS ===
"Which reduces variance?" → Bagging / Ensemble methods
"Which avoids vanishing gradients in deep networks?" → ResNet skip connections / ReLU
"Which regularisation adds weight penalty to loss?" → L1 or L2 regularisation
"What does Dropout do during inference?" → No dropout; weights scaled by (1-p)  OR inverted dropout already handles this
"Derivative of sigmoid?" → sigma(x) * (1 - sigma(x))
"Derivative of tanh?" → 1 - tanh(x)^2
"Adam combines which two ideas?" → Momentum + RMSprop / adaptive learning rates
"Which loss for binary classification?" → Binary cross-entropy
"Which gate in LSTM controls forgetting?" → Forget gate
"What is the purpose of the key in attention?" → Match with query to compute attention weights
"What is the output of softmax?" → Probability distribution (sums to 1)
"Backprop uses which mathematical rule?" → Chain rule of calculus
"SGD update rule?" → theta = theta - lr * gradient
"What is an epoch?" → One complete pass through the training dataset
"What causes mode collapse in GANs?" → Generator produces limited variety; discriminator fails to distinguish
"What is the reparameterisation trick (VAE)?" → z = mu + epsilon * sigma; allows backprop through random sampling
"Xavier initialisation is designed for?" → Saturation-based activations (sigmoid/tanh)
"He (Kaiming) initialisation is designed for?" → ReLU and its variants
"Batch size effect on generalisation?" → Larger batch → sharper minima → worse generalisation
"Which architecture uses query, key, value?" → Transformer / Attention mechanism
"Positional encoding in Transformers?" → Sine and cosine functions of different frequencies
"Number of parameters in FC layer (d_in, d_out)?" → d_in * d_out + d_out
"FLOPs in FC layer?" → approximately 2 * d_in * d_out
"What is gradient clipping?" → Cap gradient norm to prevent exploding gradients
"Which technique prevents overfitting by zeroing activations?" → Dropout
"Internal covariate shift is addressed by?" → Batch Normalisation
