## Course Integration Example

### Sample Assignment

**Title:** "Transfer Learning for Custom Image Classification"

**Objective:** Apply transfer learning principles using the RemoteSense-TransferBench project.

**Setup:**
```bash
docker-compose up remotesense-bench
# Access Jupyter at localhost:8002
```

**Tasks:**
1. Load pre-trained ResNet-50 model
2. Freeze backbone, train only classifier layer
3. Fine-tune entire network
4. Compare accuracy and training time for both approaches
5. Document findings in 2-page report

**Deliverables:**
- Trained model checkpoints
- Training logs and accuracy curves
- Written analysis comparing the two strategies

Grading rubric and detailed instructions available in project README.
